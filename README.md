# 🕊️ Project: The  邱炳坤  Project - EdgeAI Inertial Guide Glasses
### （銀髮守護者：離線 AI 智慧眼鏡計畫 —— 謹以此專案向發起人之尊長致敬）
## 📌 核心願景 (Vision)
本專案是由台灣發起人所創立的全球開源計畫。
我們旨在打造一套「無鏡頭、高隱私、零操作」的智慧眼鏡邊緣軟體系統。透過子女遠端一次性設定，讓眼鏡在「完全斷網、無 GPS」的極端環境下，純靠內建感測器進行行為學習與慣性盲算導航，精準提醒長輩吃藥運動，並指引迷路的長輩安全回家。
本專案的第一個開源版本，正式以發起人父親之名命名。這不僅是一項科技創新，更是一份將為人子女的孝心與關懷，轉化為守護全球銀髮長輩的溫暖力量。

## 🧠 核心技術架構 (Architecture)
### 1. 遠端異步同步 (Remote Async Sync)
* **邏輯**：子女端 App 在有網路時輸入常規作息與回家路線座標，透過藍牙將數據「固化」寫入眼鏡本地端 Flash 記憶體。
### 2. 邊緣 AI 情境感知 (Edge AI Contextual Awareness)
* **邏輯**：利用眼鏡內建六軸 IMU 感測器（不使用攝影鏡頭，保障隱私），由 TinyML 模型離線分析長輩動態。若提醒時間到長輩正在午睡，系統自動延後，待長輩醒來站立時才強行置頂顯示服藥/運動提示。
### 3. 離線慣性盲算導航 (Offline Inertial Dead Reckoning)
* **邏輯**：當長輩出門斷網、迷路且偏離常軌時，眼鏡自動切換至盲算模式。純粹依據加速度計與陀螺儀計算步行步長、步頻與角速度，建立相對位移向量，與預存路線比對，並在 HUD（抬頭顯示器）上投射綠色引導箭頭帶長輩回家。
